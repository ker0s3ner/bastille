Bastille / Features

Secure defaults.
Hostile assumptions.

Eight layers of protection — network, storage, access, USB, firmware, physical, anonymity, and memory — designed together so no single failure exposes everything.

Protection layers

Nothing left to configure.

Network

VPN kill-switch + HTTPS enforcement

All traffic is routed through WireGuard. nftables drops everything if the tunnel is down. Plain-HTTP connections are rejected at the firewall. DNS is locked to the system stub resolver. Firefox ships with a managed policy that disables and locks DoH — browsers without a managed policy can still bypass the resolver via port-443 DoH, so only use browsers covered by an enterprise policy.

Storage

Split-key LUKS2 encryption

Bastille supports an optional persistent encrypted partition on the same USB drive. The persistent partition is LUKS2 with Argon2id. The master key is derived from the user's passphrase and written to the kernel's logon keyring — write-once, not readable from userspace after boot. Locking the screen evicts that keyslot; the partition cannot be read again without re-entering the passphrase.

Access

Duress PINs with decoy profiles

The session auto-logs in on boot — no login prompt is shown at startup. Duress PINs apply at screen unlock only: normal unlock, decoy unlock (opens a sanitised profile), and wipe unlock (overwrites key material and powers off). PIN verification is constant-time.

⚠ Legal note: in some jurisdictions, using a wipe PIN in response to a lawful demand may constitute destruction of evidence. Know your local law before enabling this feature.

USB

USB control and counter-response

USBGuard runs in default-deny mode: any newly connected HID device is blocked until explicitly authorised. A secondary rate-monitor watches for bursts above 40 events per 100 ms. On either trigger: de-authorise, evict LUKS keys, shred key material. VID:PID signature matching is included but is spoofable and treated as supplementary.

Firmware

Sub-ring-0 neutralisation

Intel ME is stripped to the HAP bit via me_cleaner where supported. KVM modules are blacklisted at boot. S3 suspend (the SMM attack surface) is disabled. IOMMU is enforced in strict mode. A firmware audit service runs at boot and logs the result.

Requires external SPI flashing. Does not work on machines with Intel Boot Guard; check your hardware before flashing.

Physical

Vision and focus guard Opt-in

Camera-based face detection (Haar cascade, 5 fps): screen locks if your face leaves the frame for ten seconds; dims to 5% if a second face appears. Disabled by default — an active camera is its own attack surface. Enable in Bastille Settings if you want it.

Anonymity

I2P routing

i2pd runs inside the WireGuard tunnel. SOCKS5 and HTTP proxies are available on localhost for applications that support them. Traffic routed through I2P is end-to-end encrypted across the I2P network before reaching the VPN.

Memory

Minimal RAM footprint

Key material uses sodium_malloc with mlock. Page cache is scrubbed every five minutes via drop_caches. Transparent hugepages are disabled. vm.swappiness=0 prevents sensitive pages from being paged out.
