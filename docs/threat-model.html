Bastille / Threat Model

What Bastille
protects against.

Bastille is designed for people under active adversarial pressure — border crossings, device seizure, network interception. It does not protect against a fully compromised supply chain or a nation-state with physical access to the CPU die.

Context

Live system threat model.

The live OS boots entirely to RAM and leaves no artefacts on the host machine. An optional persistent encrypted partition on the same USB drive stores user data; the BFU/AFU threat model rows below apply when that partition is in use. Without it, powering off the device destroys all session state.

The user account is intentionally unprivileged — no sudo access. All persistent configuration is done through the Bastille Settings UI. System daemons run as dedicated accounts. This is a deliberate security decision, not a limitation.
