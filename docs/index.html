Privacy-hardened desktop Linux

Bastille

A Debian-based live OS built for people who need their computer to keep secrets. Forced VPN kill-switch, split-key LUKS2 encryption, duress PINs, I2P routing, and sub-ring-0 firmware hardening — on by default.

About

The OS that doesn't trust the network, the hardware, or you.

Bastille is a spiritual successor to the 2002 Shmoo Group Tinfoil Hat Linux floppy distro — updated for a threat landscape that includes hardware-level attacks, forensic extraction tools, and always-on adversarial networks. It runs as a live system off USB, boots entirely to RAM, and leaves nothing on the host machine when you remove the drive.

Every design decision assumes the worst case: the network is hostile, the USB port is a weapon, and physical access to the device is a real possibility. Bastille is not a convenience OS. It is built for people who need operational security that holds under pressure.

The build is fully reproducible from source using live-build on a Debian host. No binary blobs are added after the Debian base. Every configuration file, hook, and compiled component is in the repository.

Features

Every protection on by default. No manual configuration.

Network

VPN kill-switch + HTTPS enforcement

All traffic is routed through WireGuard. nftables drops everything if the tunnel is down. Plain-HTTP connections are rejected at the firewall. DNS is locked to the system resolver; apps cannot bypass it.

Storage

Split-key LUKS2 encryption

The LUKS master key is split: one half lives in the kernel's logon keyring (write-once, not readable from userspace), the other on the encrypted partition. Lock the screen and the device becomes Before-First-Unlock.

Access

Duress PINs with decoy profiles

Up to three PINs: normal login, decoy login (opens a clean profile, appears genuine), and full-wipe (overwrites key material and powers off without flushing disk). PIN verification is constant-time.

USB

Forensic tool detection and counter-response

A resident daemon matches connected USB devices against a database of forensic tool VID:PID signatures (Cellebrite, MSAB, Qualcomm EDL, MediaTek BROM). On match: de-authorise, evict LUKS keys, shred key material, re-authorise. Any unrecognised HID device emitting more than 40 events per 100 ms is treated as a BadUSB injection attack and blocked.

Firmware

Sub-ring-0 neutralisation

Intel ME is stripped to the HAP bit via me_cleaner. KVM modules are blacklisted at boot. S3 suspend (the SMM attack surface) is disabled. IOMMU is enforced in strict mode. A firmware audit service runs at boot and logs the result.

Physical

Vision and focus guard

Camera-based face detection runs at 5 fps. If your face leaves the frame for more than ten seconds, the screen locks. If a second face enters the frame, the screen dims to 5% brightness — without locking, so the session remains live.

Anonymity

I2P routing

i2pd runs inside the WireGuard tunnel. SOCKS5 and HTTP proxies are available on localhost for applications that support them. Traffic routed through I2P is end-to-end encrypted across the I2P network before reaching the VPN.

Memory

Minimal RAM footprint

Key material uses sodium_malloc with mlock. Page cache is scrubbed every five minutes via drop_caches. Transparent hugepages are disabled. vm.swappiness=0 prevents sensitive pages from being paged out.

Threat model

What Bastille protects against.

Bastille is designed for people under active adversarial pressure — border crossings, device seizure, network interception. It does not protect against a fully compromised supply chain or a nation-state with physical access to the CPU die.
