Bastille_OS

A Debian Bookworm live system built for minimal trust: no persistent root, AppArmor + TOMOYO mandatory-access control, OpenRC init, and WireGuard included out of the box. Boots to GNOME on x86_64 and Apple Silicon.

Overview

What Bastille gives you

[ init ]
OpenRC
Lightweight, reliable service management with no systemd dependency. elogind provides the logind interface for GNOME and PolicyKit.
[ mac ]
Dual MAC
AppArmor and TOMOYO Linux both active at boot. AppArmor profiles cover the browser and network daemons; TOMOYO provides domain-based path control.
[ vpn ]
WireGuard
WireGuard kernel module and wg-quick included. An OpenRC init script manages tunnel bring-up on boot via /etc/wireguard/wg0.conf.
[ user ]
No escalation
The live user account has no sudo access by design. System daemons run as dedicated service accounts. Privilege boundary is enforced at the account level.
[ ui ]
GNOME 43 + greetd
Full GNOME Shell desktop with mutter compositing on X11. greetd manages session handoff — configurable, no display manager daemon overhead.
[ live ]
Live / amnesic
Boots entirely from a squashfs overlay. Nothing writes to disk unless explicitly configured. Suitable for air-gapped or untrusted hardware use.

Usage

Quick start

  1. Download the ISO Go to Releases and grab the latest ISO for your architecture. Verify with the attached .sha256 file.
  2. Write to USB (bare metal) 
    # Linux / macOS — replace /dev/sdX with your drive
$ sudo dd if=bastille.iso of=/dev/sdX bs=4M status=progress conv=fsync
    On macOS use diskutil unmountDisk /dev/diskN first.
  3. Or mount in a VM Attach the ISO as a virtual optical drive. For VirtualBox ARM64: use a VirtioSCSI controller, set type to DVD. Enable EFI in the VM firmware settings.
  4. Boot Select the Live system entry from the GRUB menu. greetd starts the GNOME session automatically for the user account. No password is set on the live user.

Internals

Init system — OpenRC

Bastille uses OpenRC with sysvinit-core as PID 1. systemd is not present. Service ordering is managed by OpenRC runlevels.

Runlevel assignments

# sysinit runlevel
udev            → sysinit
udev-trigger    → sysinit

# default runlevel (multi-user)
elogind         → default   # logind replacement for GNOME/PolicyKit
dbus            → default
NetworkManager  → default
greetd          → default   # session greeter
wg-quick        → default   # optional; enable per-interface symlink

elogind

elogind provides the org.freedesktop.login1 D-Bus interface that GNOME Shell, PolicyKit, and NetworkManager depend on. It is a drop-in replacement for systemd-logind with no other systemd components required.

WireGuard VPN

WireGuard is included in the kernel and managed by an OpenRC init script at /etc/init.d/wg-quick. To activate an interface:

# Place your config at /etc/wireguard/wg0.conf, then:
rc-update add wg-quick.wg0 default
rc-service wg-quick.wg0 start

The init script handles bring-up and teardown via wg-quick up / down. Multiple tunnels are supported — create one symlink per interface name.

Build

Building locally

Requires Docker (for reproducible Debian chroot) and squashfs-tools + xorriso on the host.

git clone https://github.com/ker0s3ner/bastille.git
cd bastille

# x86_64
bash build.sh

# ARM64 (cross-build from Apple Silicon or native ARM runner)
bash build-arm64-local.sh

The build takes approximately 25–40 minutes depending on mirror speed. Output ISOs land in build/.
