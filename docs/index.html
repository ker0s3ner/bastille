Capabilities

Everything you need.
Nothing they can use.

Each feature is designed around a specific adversary capability and removes it.

🔒

Split-Key LUKS2

Disk key split across RAM (kernel logon keyring) and storage. Screen lock evicts the RAM half — device becomes BFU instantly. Argon2id, 1 GB memory cost.

AFU hardened
🛡

Ring −3 Neutralisation

Intel ME stripped with me_cleaner + HAP bit. AMD PSP surface minimised. Full firmware audit on every boot with PASS/WARN/FAIL output.

Sub-kernel
📡

VPN Kill-Switch

WireGuard tunnel enforced by nftables default-DROP. All traffic dies if the tunnel drops. DNS locked to systemd-resolved over DoT — no bypass possible.

Always-on
🔍

HTTPS-Only

nftables drops outbound TCP 80, 8080, 8000. Cleartext HTTP is structurally impossible — not just redirected. Port 443 only, through the VPN.

Enforced
🚨

Cellebrite Counter

Known forensic tool VID:PIDs trigger immediate USB de-auth, LUKS key eviction, and key-material shred — before Cellebrite gets a valid connection.

Active defence
🦠

O.MG / BadUSB Block

HID rate monitor: >40 key events / 100ms is machine speed, not human. Triggers de-auth and RAM key eviction on detection.

Real-time
🎭

Duress PINs

Separate PAM module. Normal PIN and duress PIN both return PAM_SUCCESS — coercer sees no timing difference. Actions: fake wipe, full wipe, silent, decoy.

Constant-time
👁

Vision Guard

OpenCV face detection at 5fps. No face for 10 s → lock screen + evict RAM key. Two or more faces → display dims to 5% instantly.

Camera-based
🌐

I2P Routing

i2pd runs inside the VPN tunnel. Your VPN provider sees encrypted I2P traffic, not I2P destinations. SOCKS5 on 4447, SAM on 7656.

Layered
🗂

Encrypted Profiles

Per-use-case LUKS2 containers. Switch contexts with a command. Lock one, mount another. GnuPG, Firefox, SSH, and i2pd state are all profile-local.

Isolated
🔌

USB PIN Gate

Every new USB device is de-authorised on insert. A Wayland PIN dialog must be answered before the device is allowed. Session allowlist prevents repeated prompts.

3-factor
💾

Live USB + Persistence

Boots ephemeral like Tails. Optional LUKS2-encrypted persistence partition for keys and profiles, created with one command, unlocked automatically on boot.

Optional

Threat Model

Named adversaries.
Concrete mitigations.

Physical access — AFU

  • LUKS master key readable from RAM
  • Cellebrite UFED USB acquisition
  • DMA attack via Thunderbolt
  • Memory cold-boot after lock
  • O.MG / HID injection attack

Network adversary

  • DNS interception / poisoning
  • Traffic analysis (cleartext)
  • Captive portal credential harvest
  • VPN drop → plaintext fallback
  • Browser fingerprinting via HTTP

Coercion

  • Forced PIN disclosure (duress)
  • Shoulder surfing (privacy screen)
  • Fake wipe detection via timing
  • Evidence of data under duress

Firmware / sub-kernel

  • Intel ME full activation (Ring −3)
  • KVM hypervisor modules (Ring −1)
  • /dev/mem kernel memory access
  • Unsigned kernel modules
  • SMM-based memory persistence

Build from source

# Clone and build the live ISO
$ git clone https://github.com/ker0s3ner/tinfoil-hat-linux
$ cd tinfoil-hat-linux/build
$ sudo lb clean && sudo lb config && sudo lb build

# Enroll split-key LUKS (after install)
$ sudo thl-keyguard enroll --device /dev/sda
